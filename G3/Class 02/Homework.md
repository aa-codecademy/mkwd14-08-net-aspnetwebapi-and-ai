# Homework - Class 02

## Objectives

In this homework, you'll create your first .NET Web API and implement a simple Users API using everything you've learned in class.

---

## Requirements

1. Create a new **.NET Web API** project.

2. Create a new `UsersController`.

3. Create a simple static database containing a list of user names.

4. Implement a **GET** endpoint that returns all users.

5. Implement a **GET** endpoint that returns a single user by its index or id.

---

## Bonus ⭐

Create a simple HTML page with JavaScript that calls your API endpoints and displays the returned data.

---

# 🤖 AI Guidelines

AI should help you understand the concepts—not complete the homework for you.

Use AI to:

- Explain concepts you don't understand.
- Help debug errors.
- Review your code.
- Suggest improvements after you've finished the implementation.

### Good prompts

```text
Explain how API Controllers work in .NET.
```

```text
Review my UsersController and suggest improvements without rewriting the solution.
```

```text
Help me understand why my endpoint returns a 404 response.
```

```text
Explain the difference between Controller and ControllerBase.
```

```text
Explain this compiler error without giving me the full solution.
```

### Avoid prompts like

```text
Complete the homework for me.
```

```text
Generate the entire UsersController.
```

```text
Write the whole solution.
```

The goal is to understand the implementation, not just generate working code.
